# 🚗 基于 51 单片机的四驱智能循迹小车 (SmartCar)

> 一个基于 STC89C52RC 单片机开发的高完成度四驱循迹小车项目。工程采用高度模块化设计，底层架构预留了舵机、超声波与 LCD1602 的扩展接口。实现了平滑差速循迹、硬件级 PWM 调速与蜂鸣器状态反馈，适合单片机初学者参考与进阶学习。


# 注意⚠️：此项目还处于开发阶段，仍有不少bug，两个测试部分无问题，寻迹部分可完成基础寻迹，但还有不少可以优化的地方，团队正在进行相关研究调整，敬请期待。

## 📖 项目简介

本项目主控采用 **STC89C52RC** 单片机，底盘为四驱结构（左右两侧双电机并联）。通过车头的 **TCRT5000** 红外传感器识别白底黑线，利用 **L298N** 电机驱动模块配合定时器 0 生成的 PWM 波，实现左右轮平滑差速转向与循迹。

项目采用**“分阶段验证”**的开发模式。仓库不仅包含最终成品代码，还保留了用于测试电机基础动作和 PWM 差速调参的独立工程（`test` 与 `simplestest`），还原真实的嵌入式调试流程。

*   **开发语言：** C 语言 (遵循 C89 标准)
*   **核心主控：** STC89C52RC
*   **开发环境：** Keil uVision4 (C51)
*   **烧录软件：** AiCube-ISP-v6.96C (STC-ISP)

## ✨ 核心功能与亮点

*   **平滑差速转向**：采用“外侧轮快、内侧轮慢”的差速策略（如 `SPD_TURN_OUTER = 160`），杜绝了传统循迹小车转弯时“一顿一顿”的搓车现象。
*   **极简硬件 PWM**：利用定时器 0（模式 2，8 位自动重装载）生成 100us 中断，配合三元运算符极简实现 PWM 占空比控制，CPU 开销极低。
*   **声光交互反馈**：按下 S2 按键一键启动，正常直行时静音，压线修正时蜂鸣器鸣笛提示。
*   **高可扩展底层架构**：`config.h` 中已高度封装并预留了舵机（`Servo.c`）、超声波（`Echo/Trig`）、LCD1602 的引脚与微秒级延时函数，方便后续扩展超声波避障等功能。

## 💻 开发与烧录环境说明 (极其重要)

由于 Keil 官方未原生支持 STC 芯片库，本项目采用兼容的 Atmel 芯片进行工程配置，请严格按照以下步骤操作：

1.  **Keil 编译配置**：
    *   **Device (器件选择)**：`Atmel` -> `AT89C52` (指令集完全兼容 STC89C52RC)
    *   **晶振频率 (Xtal)**：`11.0592 MHz` (与代码中的 `TH0/TL0` 初值及 `Delay.c` 强相关)
    *   编译生成 `.hex` 文件。
2.  **烧录配置 (AiCube-ISP-v6.96C)**：
    *   **芯片型号**：`STC89C52RC/LE52RC`
    *   **注意事项**：*关闭小车电源，先连接数据线，然后打开主板电源，点击“下载/编程”后，先关闭主板电源，然后拔掉数据线，才能成功烧录。*

## 🧠 踩坑与经验分享 (Developer Notes)

在开发过程中，总结出以下关键经验：

1.  **电机个体差异补偿**：相同的 PWM 占空比下，左右轮转速往往不一致。因此在直行时，代码中加入了差速补偿（如 `simplestest` 中左轮 75、右轮 100），有效解决小车天然跑偏问题。**（新换的电机无此问题）**
2.  **C89 标准限制**：Keil C51 默认遵循 C89 标准，**变量必须在代码块的最顶部声明**，不能在 `for` 循环内部定义变量（如 `for(int i=0;...)` 会报错）。
3.  **传感器电平逻辑**：本项目使用 TCRT5000 模块检测**白底黑线**。红外光照到白纸反光强，输出低电平（0）；照到黑线被吸收，输出高电平（1）。因此在 `app.c` 中，**当左侧传感器 `L == 1` 时，说明车偏右了，需要向左修正（右侧车轮加速）**。
4.  **主循环非阻塞**：在 `line-following` 的主函数中，**不要用使用长延时**，尽量不用Delay1ms()（此函数利用死循环创造延时，期间会造成主寻迹循环阻塞，严重影响性能），极大提高了红外传感器的响应速度，过弯更丝滑。
5.  **UNRESOLVED EXTERNAL 警告**：在引入舵机等扩展功能时，如果在 `.h` 中声明了微秒级延时但未在 `.c` 中实现，Keil 会报错。本项目已在 `Delay.c` 中完整恢复并实现了微秒级延时函数。
6.  用“转弯保持”，就必须加上“打断机制”——一旦在保持期间，传感器检测到了相反方向或全新的压线信号，必须立刻清空计数、打破保持，听从最新传感器的指挥！**（转弯保持使用一个计数器变量（Counter）：主循环每执行一次，计数器减 1，在计数器归零之前且没有传感器触发，强制维持转弯动作）**
7.  使用计算器变量时，初值要赋的非常大（几千）才会有明显效果，因为主循环执行一轮所需时间非常短。

## 🚀 快速开始

1.  Clone 本仓库，进入 `line-following` 文件夹。
2.  使用 Keil uVision4 打开 `.uvproj` 工程。
3.  确认器件为 `AT89C52`，晶振为 `11.0592MHz`，编译生成 `.hex`。
4.  使用 AiCube-ISP 选择 `STC89C52RC`，加载 `.hex`，下载并冷启动小车。
5.  将小车放置在白底黑线赛道上，按下 S2 按键，听到蜂鸣器提示音后即可开始自动循迹。
